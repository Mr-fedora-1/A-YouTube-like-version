# YouTube Clone

A front-end clone of the YouTube home page, built with **HTML** and **CSS** as a practice project for learning web development.

## Preview

## Features

- Top navigation bar with logo, search box, and action icons (upload, apps, notifications, profile)
- Sidebar with menu sections: Home, Explore, Subscriptions, Originals, YouTube Music
- Library section: History, Your videos, Watch later, Downloads, Liked videos
- Subscriptions list in the sidebar
- Responsive video grid (4 cards per row on desktop)
- Video cards with thumbnail, channel avatar, title, channel name, views, and upload date
- Scrollable sidebar and content area

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo>.git
   ```
2. Go into the project folder:
   ```bash
   cd <your-repo>
   ```
3. Open the page in your browser:
   ```bash
   xdg-open index.html
   ```
   Or simply double-click `index.html`.
